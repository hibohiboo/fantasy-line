# PBI-012 魔力消費をシミュレーションする

## ユーザーストーリー

管理者として、魔力消費の変化を見たい。
そうすることで、生活との関係を確認できる。

## 受け入れ条件

- [ ] 時系列で魔力消費が記録される
- [ ] 在宅時は消費が増加する
- [ ] 夜は消費が増える
- [ ] 村全体の合計も表示される

## エピック

[魔力システム](../README.md#エピック-6--魔力システム)

## 優先度

Phase 2

## 補足

このPBIが「因果関係がある」差別化の中核。  
行動（在宅/外出）→ 魔力消費量という因果が明示されることで、  
「なぜこの家の魔力が増えたのか」を説明できるシミュレーションになる。
