# PBI-017 村作成フォームのフロントエンドテストを修正する

## ユーザーストーリー

開発者として、村作成画面のバリデーション・送信テストを正常に動作させたい。
そうすることで、フロントエンドの品質を継続的に保証できる。

## 背景

`VillageCreateView.medium.test.ts` の以下3テストが JSDOM 環境での Vuetify VForm の制限により失敗している。
暫定対処として `it.skip` でスキップ済み。

- 空文字で送信するとバリデーションエラーが表示され遷移しない
- 129文字で送信するとバリデーションエラーが表示され遷移しない
- 正常送信後に /villages へリダイレクトする

## 原因の仮説

Vuetify の `v-form` ref が JSDOM 環境で正しく解決されず、`form.value?.validate()` が `undefined` を返すため、
バリデーションが実行されずに早期 return している可能性が高い。

## 受け入れ条件

- [ ] `it.skip` を外した状態で3テストがすべて通過する
- [ ] 実ブラウザ上のフォーム動作（バリデーション表示・リダイレクト）が引き続き機能する
- [ ] lint・型チェックが通過する

## 対応方針（候補）

1. **コンポーネント修正案**: `v-form ref` + `validate()` をやめ、`onSubmit` 内で Zod バリデーションを手動実行し、エラーを `:error-messages` や `v-if` で表示する
2. **テスト修正案**: `form.validate` をモックしてテスト側で制御する
