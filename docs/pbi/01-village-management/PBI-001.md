# PBI-001 村を作成する

## ユーザーストーリー

As a 村の管理者（ゲームマスター）
I want 村名を入力して自分の村を作成したい
So that ファンタジー世界の管理を開始できる

## 背景 / 目的

プロダクトの起点となるPBI。村が存在しなければ住人・職業・シミュレーションのいずれも成立しない。管理者が自分の村を所有・管理できる最小単位を確立する。

## スコープ

- 含む
  - 村名の入力・保存（最大128文字）
  - 作成者を管理者として関連付け
  - 作成した村の一覧表示（自分の村のみ）
  - 他ユーザーの村への編集ガード
- 含まない
  - 村の詳細設定（昼夜サイクルなど → PBI-002）
  - 村の削除・アーカイブ
  - 複数管理者の設定
  - 村のテンプレートや複製
  - ログイン機能（→ PBI-014）

## ユースケース

### メイン

1. 管理者が「村を作成」ボタンを押す
2. 村名を入力して「作成」を実行する
3. 作成者が管理者として登録される
4. 村一覧に新しい村が表示される

### 代替

- 村名未入力のままで作成しようとした場合 → バリデーションエラーを表示
- 村名が128文字を超える場合 → バリデーションエラーを表示

### 例外

- 未ログイン状態でアクセスした場合 → ログイン画面にリダイレクト

## 受け入れ条件（Gherkin）

```gherkin
Scenario 1: 正常に村を作成できる
  Given 管理者がログインしている
  When 村名「エルムの村」を入力して作成を実行する
  Then 村が保存される
  And 作成者が管理者として登録される
  And 村一覧に「エルムの村」が表示される

Scenario 2: 同名の村を複数作成できる
  Given 管理者がログインしており、すでに「エルムの村」が存在する
  When 再び村名「エルムの村」を入力して作成を実行する
  Then 2つ目の「エルムの村」が保存される
  And 村一覧に「エルムの村」が2件表示される

Scenario 3: 村名が空の場合は作成できない
  Given 管理者がログインしている
  When 村名を空のまま作成を実行する
  Then バリデーションエラーが表示される
  And 村は作成されない

Scenario 4: 村名が128文字を超える場合は作成できない
  Given 管理者がログインしている
  When 129文字の村名を入力して作成を実行する
  Then バリデーションエラーが表示される
  And 村は作成されない

Scenario 5: 他ユーザーの村は編集できない
  Given ユーザーAが作成した村「エルムの村」が存在する
  When ユーザーBが「エルムの村」の編集を試みる
  Then 編集が拒否される（権限エラーまたは編集UIが非表示）

Scenario 6: 村一覧には自分の村のみ表示される
  Given ユーザーAの村「エルムの村」とユーザーBの村「オークの村」が存在する
  When ユーザーAが村一覧を表示する
  Then 「エルムの村」のみが表示される
  And 「オークの村」は表示されない
```

## ルール（Example Mapping）

- Rule 1: 村名は必須・最大128文字
  - Example: 空文字で作成 → エラー
  - Example: 128文字の村名で作成 → 成功
  - Example: 129文字の村名で作成 → エラー
- Rule 2: 同名の村は複数作成可能
  - Example: 「エルムの村」が既存でも「エルムの村」を再作成 → 成功
- Rule 3: 作成者は自動的に管理者になる
  - Example: ユーザーAが作成 → 管理者はユーザーA
- Rule 4: 他ユーザーの村は編集不可
  - Example: ユーザーBがユーザーA所有の村を編集 → 拒否
- Rule 5: 村一覧には自分の村のみ表示
  - Example: ユーザーAの一覧にはユーザーAの村のみ表示
- Rule 6: 村の作成数に上限なし
  - Example: 100村作成済みでも追加作成可能
