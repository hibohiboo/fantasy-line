# PBI-008 村全体の1日を生成する

## ユーザーストーリー

管理者として、村全体の1日を生成したい。
そうすることで、村の動きを俯瞰できる。

## 受け入れ条件

- [ ] 全住人の行動が同時に生成される
- [ ] 時刻ごとの活動人数が集計される
- [ ] 同一時間に複数の行動が重なる

## エピック

[1日シミュレーション](../README.md#エピック-4--1日シミュレーション)

## 優先度

MVP

## 補足

PBI-007（住人個別）の拡張。  
全住人分の DailySimulation を一括生成し、時刻軸で集計する。  
この集計データが PBI-010（ヒートマップ）の入力になる。
