# PBI-007 住人の1日を生成する

## ユーザーストーリー

管理者として、住人の1日の行動を生成したい。
そうすることで、世界が動いている様子を確認できる。

## 受け入れ条件

- [ ] 指定日でシミュレーションが実行できる
- [ ] 各住人に対してタイムラインが生成される
- [ ] 起床・仕事・休憩・就寝が含まれる
- [ ] 毎回少し異なる結果になる

## エピック

[1日シミュレーション](../README.md#エピック-4--1日シミュレーション)

## 優先度

**MVP 最重要**

## 補足

このPBIがプロダクトの核心。  
「テンプレート（ScheduleTemplate）」から「生成結果（DailySimulation）」を生み出す処理として実装する。  
ばらつきは `±分` の範囲でランダム化し、毎回異なる結果を担保する。
