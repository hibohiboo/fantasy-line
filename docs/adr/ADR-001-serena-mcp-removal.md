# ADR-001: Serena MCP サーバーを削除する

- **ステータス**: 採用
- **決定日**: 2026-06-18
- **決定者**: hibohiboo

---

## 背景

Claude Code の開発支援として Serena MCP サーバー（[oraios/serena](https://github.com/oraios/serena)）を導入していた。
Serena はプロジェクトのコードベース構造を記憶し、セッション中の不要なファイル読み込みを減らすことでトークンを削減するツールである。

導入後、トークンコストへの影響について相反する情報が存在し、本プロジェクトへの適合性を評価する必要が生じた。

参考情報:
- 記事 A（note）: MCP 導入によりセッション開始前に **66,000 トークン**が消費される。Claude Code 2.x 標準機能で代替可能。https://note.com/euro0202/n/na6551077349a
- 記事 B（Qiita）: Serena 有効化で出力トークン約 **43% 削減**・総コスト約 **56% 削減**（Sonnet 4.5 / 単一プロジェクト簡易計測）。https://qiita.com/YasuhiroKawano/items/27edcee5e4e6aed26306

---

## 決定

**Serena MCP サーバーを `.claude/settings.json` から削除する。**

---

## 採用理由

### 1. 損益分岐点に本プロジェクトのセッション長が届かない

| 項目 | 値 |
|---|---|
| Serena の起動コスト（固定） | 約 66,000 トークン |
| セッション中の 1 ターンあたり削減量（記事 B より推算） | 約 500 トークン |
| 損益分岐ターン数 | 66,000 ÷ 500 = **約 130 ターン** |

本プロジェクトは個人学習プロジェクトで短時間の機能実装セッションが中心。
130 ターンを超えるセッションは例外的であり、大半のセッションで起動コストが削減効果を上回る。

### 2. Claude Code 2.x 標準機能で代替可能

| Serena の機能 | 代替手段 |
|---|---|
| プロジェクト構造の記憶・再利用 | `CLAUDE.md` + `.claude/instructions/*.md` |
| コードベースの検索・調査 | Explore エージェント（Agent ツール） |
| セッション横断の知識保存 | `/memory` コマンド |

本プロジェクトはすでに `.claude/instructions/*.md` が充実しており、Serena の project knowledge と機能が重複する。

### 3. 起動方式がネットワーク依存でリスクがある

```json
"command": "uvx",
"args": ["--from", "git+https://github.com/oraios/serena", ...]
```

毎回 git リポジトリからフェッチするため、ネットワーク障害・GitHub 障害・バージョン変更の影響を受ける。
固定バージョンでも `@latest` 相当の挙動となりやすく、再現性が低い。

### 4. AWS コスト最優先方針との整合

本プロジェクトは AWS 利用料・AI API コストを低く保つことが最優先制約のひとつ。
効果が不確かな場合はシンプル構成（削除）を優先する方針と合致する。

---

## 代替案と却下理由

### 案 B: Serena を継続する

- **却下理由**: 損益分岐（130 ターン超）に届かないセッションが大半。記事 B の計測は Sonnet 4.5 であり Sonnet 4.6 での検証がない。Claude Code 標準機能で代替できるため、継続のメリットが薄い。

### 案 C: セッション傾向を計測してから判断する

- **却下理由**: 計測にかかるコストと時間が、不確かな利益を正確に測るには不均衡。現時点で削除が有利な条件が複数揃っており、計測を待つ合理的な理由がない。

---

## 採用しない条件（見直し条件）

以下の条件が生じた場合は、Serena の再導入を検討する。

1. セッション長が常態的に 150 ターンを超えるようになった場合
2. Claude Code の Explore エージェントや `/memory` では解決できないコード探索課題が繰り返し発生した場合
3. Serena が固定バージョンの `pip install` / `uvx --python` で安定導入できるようになり、起動の再現性が確保された場合

---

## 影響

| 観点 | 内容 |
|---|---|
| **コスト** | セッション開始前の 66,000 トークン消費がなくなる |
| **起動速度** | git フェッチがなくなり、セッション開始が速くなる |
| **コード探索** | Explore エージェントで代替。シンボル一覧取得などの Serena 固有機能は使えなくなる |
| **知識保存** | `/memory` コマンドで代替。Serena の memory ファイルは削除しない（参照可能に残す） |
| **安定性** | ネットワーク依存の起動がなくなり、オフライン環境でも Claude Code が起動しやすくなる |

---

## 実施内容

`.claude/settings.json` の `mcpServers` から `serena` エントリを削除する。
