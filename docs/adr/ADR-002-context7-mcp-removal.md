# ADR-002: context7 MCP サーバーを削除する

- **ステータス**: 採用
- **決定日**: 2026-06-18
- **決定者**: hibohiboo

---

## 背景

Claude Code の開発支援として context7 MCP サーバー（`@upstash/context7-mcp`）を導入していた。
context7 はライブラリの公式ドキュメントを LLM 向けに整形し、バージョン対応のドキュメントをピンポイントで取得できるツールである。

評価にあたり以下の事実が判明した。

1. `.claude/settings.json` の `CONTEXT7_API_KEY` が空文字 `""` になっており、現状では機能していない可能性が高い
2. Claude Code には WebSearch・WebFetch が標準搭載されており、公式ドキュメントへの直接アクセスが可能
3. MCP サーバーのツール説明文はセッション開始時にトークンとして消費される

---

## 決定

**context7 MCP サーバーを `.claude/settings.json` から削除する。**

---

## 採用理由

### 1. API キーが空で現状機能していない

```json
"context7": {
  "command": "npx",
  "args": ["-y", "@upstash/context7-mcp@latest"],
  "env": {
    "CONTEXT7_API_KEY": ""
  }
}
```

`CONTEXT7_API_KEY` が空文字のまま運用されており、実質的にドキュメント取得が機能しない状態でも
ツール説明文のトークンだけが起動時に消費されている。機能しないサービスのためにコストを払い続けている状態。

### 2. WebSearch / WebFetch で代替可能

| context7 の用途 | 代替手段 |
|---|---|
| AWS CDK API リファレンス | WebFetch → `https://docs.aws.amazon.com/cdk/api/v2/` |
| Vue 3 公式ドキュメント | WebFetch → `https://vuejs.org/guide/` |
| Vitest ドキュメント | WebFetch → `https://vitest.dev/` |
| Drizzle ORM ドキュメント | WebFetch → `https://orm.drizzle.team/` |
| ライブラリ全般 | WebSearch → ライブラリ名 + バージョン + キーワード |

本プロジェクトで使用するライブラリはすべて公式 URL が既知であり、WebFetch で直接アクセスできる。

### 3. 最新情報への直接アクセスのほうが鮮度が高い

context7 はドキュメントを中間サービスを経由して取得する。公式ドキュメントに直接 WebFetch するほうが鮮度・確実性が高い。

### 4. AWS コスト最優先方針との整合

機能しない MCP を維持してトークンコストだけ発生させることは、コスト最優先方針に反する。

---

## 代替案と却下理由

### 案 B: API キーを設定して context7 を継続する

- **却下理由**: 有効化にかかる手順コストに対し、WebFetch/WebSearch で十分な代替が可能。
  context7 がライブラリドキュメントを取得する仕組みは公式 URL への直接アクセスと比べて本質的な優位性がない。
  また `@latest` 取得のためバージョン固定ができず、動作変化のリスクがある。

### 案 C: API キーなしのまま継続する

- **却下理由**: 機能しない状態でツール説明文のトークンだけが消費され続ける。純粋なコスト負債であり継続の理由がない。

---

## 採用しない条件（見直し条件）

以下の条件が生じた場合は、context7 または同等ツールの再導入を検討する。

1. WebFetch では解決できないライブラリドキュメントの取得課題が繰り返し発生した場合
2. context7 が API キーなし（またはローカル動作）で機能するバージョンが提供され、起動コストが無視できる水準になった場合
3. 扱うライブラリが増加し、URL 管理よりもドキュメント集約ツールが明らかに効率的になった場合

---

## 影響

| 観点 | 内容 |
|---|---|
| **コスト** | 非機能状態での起動トークン消費がなくなる |
| **ドキュメント参照** | WebFetch で公式 URL に直接アクセスする運用に切り替わる |
| **ワークフロー変化** | context7 のツール呼び出しの代わりに WebFetch を明示的に使う。実質的な変化は小さい |

---

## 実施内容

`.claude/settings.json` の `mcpServers` から `context7` エントリを削除する。
