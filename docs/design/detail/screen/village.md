# 画面設計 — 村管理（開発者向け）

## 対象読者

フロントエンド担当の開発者。実装前に本ドキュメントと [スタイルガイド](../../style-guide.md) を合わせて確認すること。
ユーザー視点の振る舞いは [PO向け画面設計](../../screen/village.md) を参照すること。

---

## ソート順

村一覧はサーバー側で作成日時の降順（新しい順）に並べて返す。

フロントエンド側でのソートは行わない。将来ページネーションが入った場合、フロントソートはページをまたいで正確に機能しないため。

---

## 村一覧画面

ページヘッダーに「村一覧」タイトルと「村を作成する」ボタンを配置する。

以下の状態を表示する:
- ローディング中: ローディングインジケーターを表示する
- エラー: エラーアラートを表示する
- 村がない: 空状態のメッセージを表示する
- 村がある: 村カードをグリッドで表示する（PC: 3列、タブレット: 2列、スマートフォン: 1列）

マウント時に村一覧を取得する。

---

## 村カード

村データを受け取り表示する。

村名と作成日を表示する。

### 日付フォーマット

作成日は `yyyy-MM-dd HH:mm:ss` 形式の日本時間（JST）で表示する。
実行環境のシステムタイムゾーンに依存せず、明示的に Asia/Tokyo を指定して変換するため、
デプロイ環境に関わらず一貫した表示ができる。

---

## 村作成画面

村名入力フィールドと「作成する」「キャンセル」ボタンを持つフォームを表示する。
フォーム幅は最大 600px に制限する。
APIエラー時はフォーム下部にエラーアラートを表示する。

### フォームフィールド

村名フィールドは最大 128 文字で、バリデーションルールは共有スキーマから直接参照する。
スキーマの制約が変更されたとき、フロントエンドのバリデーションも自動的に追従する。

### 送信フロー

フォームバリデーションを通過した場合のみ API を呼び出す。
作成成功時は村一覧ページに遷移する。
失敗時はエラーメッセージをフォーム下部に表示する。

### エラー表示の使い分け

| エラー種別 | 表示場所 | Vuetify コンポーネント |
|---|---|---|
| 必須未入力・文字数超過 | フィールド直下 | `v-text-field` の `:rules` |
| API バリデーションエラー (400) | フォーム下部 | `v-alert type="error"` |
| ネットワークエラー・その他 | フォーム下部 | `v-alert type="error"` |
