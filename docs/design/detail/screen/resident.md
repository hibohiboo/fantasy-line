# 画面設計 — 住人管理（開発者向け）

## 対象読者

フロントエンド担当の開発者。実装前に本ドキュメントと [スタイルガイド](../../style-guide.md) を合わせて確認すること。
ユーザー視点の振る舞いは [PO向け画面設計](../../screen/resident.md) を参照すること。

---

## ソート順

すべての住人一覧は `name_kana ASC` でソートする。
APIハンドラーのクエリに `ORDER BY name_kana ASC` を付与する。

フロントエンド側でのソートは行わない。将来ページネーションが入った場合、フロントソートはページをまたいで正確に機能しないため。

---

## 全住人一覧画面

ページヘッダーに「住人一覧」タイトルと「住人を追加する」ボタンを配置する。

以下の状態を表示する:
- ローディング中: ローディングインジケーターを表示する
- エラー: エラーアラートを表示する
- 住人がない: 空状態のメッセージと「住人を追加する」ボタンを表示する
- 住人がある: 住人一覧テーブルを表示する

### テーブルヘッダー

| カラム | 対応フィールド | スマホ表示 |
|---|---|---|
| 名前 | `name` | 表示 |
| 読み | `nameKana` | 非表示（`d-none d-sm-table-cell`） |
| 生年月日 | `birthDate` | 非表示（`d-none d-sm-table-cell`） |
| 所属村 | `villageName` | 非表示（`d-none d-sm-table-cell`） |

マウント時に住人一覧を取得する。

空状態には「住人が登録されていません」と「住人を追加する」ボタンを表示する。

---

## 村別住人一覧画面

ページヘッダーに「{村名} の住人一覧」タイトルと「住人を追加する」ボタンを配置する。
「住人を追加する」ボタンは住人登録画面に遷移し、村 ID をパラメータとして引き継ぐ。

以下の状態を表示する:
- ローディング中: ローディングインジケーターを表示する
- エラー: エラーアラートを表示する
- 住人がない: 空状態のメッセージを表示する
- 住人がある: 住人一覧テーブルを表示する（所属村カラムなし）

マウント時に URL の村 ID をもとに村別住人一覧を取得する。

---

## 住人登録画面

名前・読み・生年月日・所属村の入力フォームと「登録する」「キャンセル」ボタンを表示する。
フォーム幅は最大 600px に制限する。
APIエラー時はフォーム下部にエラーアラートを表示する。

### フォームフィールド詳細

各フィールドのバリデーションルールは共有スキーマから直接参照する。
スキーマの制約が変更されたとき、フロントエンドのバリデーションも自動的に追従する。

所属村ドロップダウンは自分の村一覧を取得してリスト表示する。
マウント時に村一覧を取得する。

### 送信フロー

フォームバリデーションを通過した場合のみ API を呼び出す。
登録成功時は全住人一覧ページに遷移する。
失敗時はエラーメッセージをフォーム下部に表示する。

### エラー表示の使い分け

| エラー種別 | 表示場所 | Vuetify コンポーネント |
|---|---|---|
| 必須未入力 | フィールド直下 | `v-text-field` / `v-select` の `:rules` |
| カタカナ形式エラー | フィールド直下（読みフィールド） | `v-text-field` の `:rules` |
| API バリデーションエラー (400) | フォーム下部 | `v-alert type="error"` |
| 権限エラー (403) | フォーム下部 | `v-alert type="error"` |
| ネットワークエラー・その他 | フォーム下部 | `v-alert type="error"` |
