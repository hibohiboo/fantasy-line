# 画面設計 — 村管理（PO向け）

## 対象読者

プロダクトオーナー・レビュアー。受け入れ条件と画面の振る舞いを確認するために参照すること。

## 画面一覧

| パス | 画面名 | 説明 |
|---|---|---|
| `/villages` | 村一覧 | 自分が作成した村をカード形式で表示する |
| `/villages/new` | 村作成 | 村名を入力して村を作成するフォーム |

---

## 表示順の方針

村一覧は **作成日の新しい順（降順）** で表示する。
ユーザーが直前に作った村をすぐ確認できるようにするため。

---

## 村一覧画面（`/villages`）

### 画面イメージ

```
┌─────────────────────────────────────────────┐
│  村一覧                    ［村を作成する］  │
├─────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌──────────────────┐  │
│  │ エルムの村        │  │ オークの村        │  │
│  │ 2026-05-05 09:00 │  │ 2026-05-04 12:30 │  │
│  └──────────────────┘  └──────────────────┘  │
└─────────────────────────────────────────────┘
```

### 状態別の表示

| 状態 | ユーザーに見えるもの |
|---|---|
| 読み込み中 | 画面中央にローディングアニメーションを表示する |
| 村が 0 件 | 「村がありません。最初の村を作成しましょう。」と「村を作成する」ボタンを表示する |
| 村が 1 件以上 | 作成日の新しい順にカードを並べて表示する |
| 読み込み失敗 | 「村一覧の取得に失敗しました。再読み込みしてください。」をページ上部に表示する |

### 各カードに表示する情報

- 村名
- 作成日時（例: 2026-05-05 09:00:00）— `yyyy-MM-dd HH:mm:ss` 形式の日本時間（JST）で表示する

## 村作成画面（`/villages/new`）

### 画面イメージ

```
┌─────────────────────────────────────────────┐
│  村を作成する                                │
├─────────────────────────────────────────────┤
│                                             │
│  村名  ____________________________  0/128  │
│                                             │
│          ［ キャンセル ］  ［ 作成する ］    │
│                                             │
└─────────────────────────────────────────────┘
```

### 操作と結果

| 操作 | 結果 |
|---|---|
| 「キャンセル」ボタンを押す | 村一覧画面（`/villages`）に戻る |
| 村名を空のまま「作成する」を押す | 「村名を入力してください」というエラーを表示する。画面遷移しない |
| 村名を 129 文字以上で「作成する」を押す | 「村名は128文字以内で入力してください」というエラーを表示する。画面遷移しない |
| 正しい村名で「作成する」を押す | ボタンが読み込み中の表示になり、村一覧画面に遷移する |
| 作成に失敗した場合 | 「村の作成に失敗しました。再試行してください。」をフォーム下部に表示する |
