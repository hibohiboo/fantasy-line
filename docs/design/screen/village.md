# 画面設計 — 村管理（village）

## 対象読者

フロントエンド担当の開発者。実装前に本ドキュメントと [スタイルガイド](../style-guide.md) を合わせて確認すること。

---

## 画面一覧

| パス | 画面名 | 説明 |
|---|---|---|
| `/villages` | 村一覧 | 自分の村をカードグリッドで表示する |
| `/villages/new` | 村作成 | 村名を入力して村を作成するフォーム |

---

## ソート順の方針

**API 側（DB の `ORDER BY created_at DESC`）でソートする。**

- 一覧は「最近作った村が上」が自然な期待順序
- 将来ページネーションが入った場合、フロントでのソートはページをまたいで正確に機能しない
- フロント側のソート切り替え UI は PBI-001 スコープ外。将来 PBI で追加する

この方針に基づき、`listVillages` ハンドラーのクエリに `ORDER BY created_at DESC` を付与する（実装計画 Phase 4 のリファクタリング対象として追記）。

## 村一覧画面（`/villages`）

### レイアウト

```
┌─────────────────────────────────────────────┐
│  村一覧                    ［村を作成する］  │  ← ページヘッダー
├─────────────────────────────────────────────┤
│  ┌───────────┐  ┌───────────┐  ┌──────────┐ │
│  │ エルムの村 │  │ オークの村 │  │ 竜の巣  │ │  ← カードグリッド
│  │ 2026-05-05 │  │ 2026-05-04 │  │ 2026-... │ │     （最新順）
│  └───────────┘  └───────────┘  └──────────┘ │
└─────────────────────────────────────────────┘
```

### 状態別の表示

| 状態 | 表示内容 |
|---|---|
| ローディング中 | `v-progress-circular` をページ中央に表示 |
| 村が 0 件 | `v-empty-state`（icon: `mdi-castle`、タイトル: 「村がありません」、テキスト: 「最初の村を作成しましょう。」、アクション: 「村を作成する」ボタン） |
| 村が 1 件以上 | カードグリッドを表示 |
| API エラー | `v-alert type="error"` をグリッド上部に表示（「村一覧の取得に失敗しました。再読み込みしてください。」） |

### コンポーネント構成

```
VillageListView.vue
├── v-container
│   ├── v-row（ページヘッダー行）
│   │   ├── v-col: h1.text-headline-large「村一覧」
│   │   └── v-col.text-right: v-btn color="primary" to="/villages/new"「村を作成する」
│   ├── v-alert（APIエラー時のみ表示）
│   ├── v-progress-circular（ローディング中のみ表示）
│   ├── v-empty-state（村が0件のみ表示）
│   └── v-row（カードグリッド）
│       └── v-col[cols=12 sm=6 md=4] × 村の数
│           └── VillageCard.vue
```

### VillageCard.vue

```
┌─────────────────────────────┐
│  エルムの村                  │  ← v-card-title（text-title-large）
│  作成日: 2026-05-05         │  ← v-card-subtitle（text-body-medium / medium-emphasis）
└─────────────────────────────┘
```

- `village` を props で受け取る（型: `VillageResponse`）
- 作成日のフォーマット: `YYYY-MM-DD`（`createdAt` を `toLocaleDateString('ja-JP')` で変換）
- 詳細ページへのリンクは PBI-002 以降。PBI-001 ではカードは表示専用

**Props:**

```typescript
defineProps<{ village: VillageResponse }>()
```

## 村作成画面（`/villages/new`）

### レイアウト

```
┌─────────────────────────────────────────────┐
│  村を作成する                                │  ← ページタイトル
├─────────────────────────────────────────────┤
│                                             │
│  村名  ____________________________  0/128  │  ← v-text-field（counter付き）
│                                             │
│  ［ キャンセル ］  ［ 作成する ▶ ］         │  ← アクションボタン
│                                             │
│  ⚠ API エラーメッセージ（失敗時のみ）        │  ← v-alert type="error"
│                                             │
└─────────────────────────────────────────────┘
```

### コンポーネント構成

```
VillageCreateView.vue
└── v-container（max-width: 600px）
    ├── h1.text-headline-large「村を作成する」
    ├── v-form（ref="form"）
    │   ├── v-text-field（村名入力）
    │   └── v-row（ボタン行）
    │       ├── v-col: v-btn variant="outlined" to="/villages"「キャンセル」
    │       └── v-col: v-btn color="primary" :loading="isSubmitting"「作成する」
    └── v-alert type="error"（APIエラー時のみ表示）
```

### フォームフィールド詳細

| 項目 | 値 |
|---|---|
| ラベル | 「村名」 |
| placeholder | （なし） |
| maxlength | 128 |
| counter | あり（文字数カウンターを表示） |
| バリデーションルール | required: 「村名を入力してください」<br>maxLength(128): 「村名は128文字以内で入力してください」 |
| バリデーションタイミング | 送信ボタン押下時（`v-form` の `validate()` を呼ぶ） |

### インタラクション仕様

| 操作 | 動作 |
|---|---|
| 「キャンセル」ボタン押下 | `/villages` に遷移（`router.push`） |
| 「作成する」押下 / バリデーション失敗 | フィールドにエラーメッセージを表示。API リクエストは送信しない |
| 「作成する」押下 / バリデーション通過 | ボタンを `:loading` 状態にして `POST /villages` を送信 |
| API 成功（201） | `/villages` にリダイレクト |
| API エラー（400） | `v-alert type="error"` に「入力内容を確認してください」を表示。フィールドエラーがあれば `fieldErrors` をフィールド下に表示 |
| API エラー（その他） | `v-alert type="error"` に「村の作成に失敗しました。再試行してください。」を表示 |
