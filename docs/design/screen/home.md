## トップページ（`/`）

### 画面イメージ — 未ログイン時

```
┌─────────────────────────────────────────────┐
│  ファンタジーライン                  ［村一覧］ │
├─────────────────────────────────────────────┤
│                                             │
│         ファンタジーライン                   │
│    村を育て、ファンタジー世界を管理する台帳    │
│                                             │
│    ┌──────────────────────────────────┐     │
│    │ 冒険者の名前を入力してください       │     │
│    └──────────────────────────────────┘     │
│                                             │
│                 ［ 始める ］                  │
│                                             │
└─────────────────────────────────────────────┘
```

### 画面イメージ — ログイン済み時

```
┌─────────────────────────────────────────────┐
│  ファンタジーライン                  ［村一覧］ │
├─────────────────────────────────────────────┤
│                                             │
│         ファンタジーライン                   │
│    村を育て、ファンタジー世界を管理する台帳    │
│                                             │
│    おかえりなさい、アリス さん               │
│                                             │
│               ［ 村一覧を見る ］              │
│                                             │
└─────────────────────────────────────────────┘
```

### 操作と結果

| 操作 | 結果 |
|---|---|
| ユーザー名を入力せず「始める」を押す | ボタンが無効状態のため押せない |
| ユーザー名を入力して「始める」を押す | ユーザー名を保存し、村一覧画面（`/villages`）に遷移する |
| ログイン済み状態でトップページを開く | ユーザー名の代わりに「おかえりなさい」メッセージと「村一覧を見る」ボタンを表示する |
| 「村一覧を見る」ボタンを押す | 村一覧画面（`/villages`）に遷移する |
| ヘッダーの「村一覧」リンクを押す（未ログイン時） | トップページ（`/`）に戻る（認証ガードによるリダイレクト） |
| ヘッダーの「村一覧」リンクを押す（ログイン済み） | 村一覧画面（`/villages`）に遷移する |
