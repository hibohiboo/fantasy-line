# 画面設計 — 住人管理（PO向け）

## 対象読者

プロダクトオーナー・レビュアー。受け入れ条件と画面の振る舞いを確認するために参照すること。
実装の詳細（コンポーネント構成・Vuetify 選定）は [開発者向け画面設計](../detail/screen/resident.md) を参照すること。

---

## 画面一覧

| パス | 画面名 | 説明 |
|---|---|---|
| `/residents` | 住人一覧 | 自分が管理するすべての村の住人を読み昇順で表示する（所属村名の列あり） |
| `/residents/new` | 住人登録 | 名前・読み・生年月日・所属村を入力して住人を登録するフォーム |
| `/villages/:id/residents` | 村別住人一覧 | 指定した村に所属する住人を読み昇順で表示する（所属村名の列なし） |

---

## 表示順の方針

住人一覧はすべて **読み（カタカナ）の昇順** で表示する。
「アキコ」→「ジロウ」→「タロウ」のように五十音順で並ぶため、目的の住人を素早く探せる。

## 住人一覧画面（`/residents`）

### 画面イメージ

```
┌─────────────────────────────────────────────────────────┐
│  住人一覧                            ［住人を追加する］  │
├─────────────────────────────────────────────────────────┤
│  名前      読み      生年月日      所属村                │
│  ─────────────────────────────────────────────────────  │
│  アキコ    アキコ    1995-03-10    エルムの村            │
│  ジロウ    ジロウ    1988-07-22    オークの村            │
│  タロウ    タロウ    2000-01-15    エルムの村            │
└─────────────────────────────────────────────────────────┘
```

### 状態別の表示

| 状態 | ユーザーに見えるもの |
|---|---|
| 読み込み中 | 画面中央にローディングアニメーションを表示する |
| 住人が 0 件 | 「住人が登録されていません。追加してください」と「住人を追加する」ボタンを表示する |
| 住人が 1 件以上 | 読み昇順に一覧を表示する |
| 読み込み失敗 | 「住人一覧の取得に失敗しました。再読み込みしてください。」をページ上部に表示する |

### 一覧に表示する情報

- 名前
- 読み
- 生年月日（例: 2000-01-15）
- 所属村名

## 住人登録画面（`/residents/new`）

### 画面イメージ

```
┌────────────────────────────────────────────────────┐
│  住人を登録する                                     │
├────────────────────────────────────────────────────┤
│                                                    │
│  名前    ____________________________  0/128        │
│                                                    │
│  読み    ____________________________  0/128        │
│          （カタカナで入力してください）              │
│                                                    │
│  生年月日  [________]                              │
│                                                    │
│  所属村  [▼ 村を選択してください ]                 │
│                                                    │
│            ［ キャンセル ］  ［ 登録する ］          │
│                                                    │
└────────────────────────────────────────────────────┘
```

### 操作と結果

| 操作 | 結果 |
|---|---|
| 「キャンセル」ボタンを押す | 住人一覧画面（`/residents`）に戻る |
| 名前を空のまま「登録する」を押す | 「名前は必須です」というエラーを表示する。画面遷移しない |
| 読みを空のまま「登録する」を押す | 「読みは必須です」というエラーを表示する。画面遷移しない |
| 読みにカタカナ以外を入力して「登録する」を押す | 「読みはカタカナで入力してください」というエラーを表示する。画面遷移しない |
| 生年月日を空のまま「登録する」を押す | 「生年月日は必須です」というエラーを表示する。画面遷移しない |
| 正しい内容で「登録する」を押す | ボタンが読み込み中の表示になり、住人一覧画面に遷移する |
| 登録に失敗した場合 | 「住人の登録に失敗しました。再試行してください。」をフォーム下部に表示する |

### 名前の文字数制限

名前・読みともに 128 文字を超えて入力できない（入力フィールドでブロック）。
128 文字制限に関するエラーメッセージは表示しない。

## レスポンシブ対応

| 画面幅 | 一覧の表示形式 |
|---|---|
| スマートフォン（〜599px） | 表形式（カラム数を減らす） |
| タブレット（600px〜） | 表形式（全カラム表示） |
| PC（960px〜） | 表形式（全カラム表示） |
