PBIドキュメントを確認・整理します。

# タスク

以下を実施してください：

1. `docs/pbi/` または指定されたディレクトリにある PBI ファイルを検索して読み込む
2. 対象の PBI が存在しない場合は `/pbi` コマンドの形式に従って新規作成する
3. 以下の項目を整理・確認し、不足があれば補完する：
   - PBI番号・タイトル
   - ユーザーストーリー（As a / I want / So that）
   - 受け入れ条件（Gherkin形式）
   - スコープ（含む / 含まない）
   - INVESTチェック

# 完了条件

- PBIドキュメントが存在し、上記項目が揃っていること
- 不明点・質問事項が明記されていること
- 完了後は「PBI確認完了」とチャットに書き込むこと
