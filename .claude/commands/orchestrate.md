# 進め方

orchestrator.md の **必須 3 フェーズ（順序厳守）** に従うこと。

## Phase 1: 方針検討

1. プロジェクトの現状を調査する
2. 問題点・背景を整理する
3. 対応選択肢を列挙し、トレードオフを比較する
4. 推奨方針と次フェーズで作成するドキュメント一覧をユーザーに提示する
5. **ユーザーの承認を得てから Phase 2 へ進む**

## Phase 2: ドキュメント作成

1. Phase 1 の方針をドキュメント（設計書 / PBI / ADR）として `docs/` に保存する
2. **ユーザーの承認を得てから Phase 3 へ進む**

## Phase 3: 実装

1. タスクを最小サブタスクに分解し、依存関係を明示する
2. 各サブタスクを適切な SubAgent に割り当て、Agent ツールで実行する
3. 全サブタスク完了後に未解決事項を明示する
4. `docs/pbi/README.md` の該当 PBI を `✅ 完了` に更新する
5. **ユーザーの承認を得てから完了とする**

## 禁止事項

- Phase をユーザー確認なくスキップしない
- ドキュメント作成を省略して実装に直行しない
- 実装をすべて自分で抱え込む（SubAgent に委譲する）
- ユーザー確認なしに完了扱いにする
