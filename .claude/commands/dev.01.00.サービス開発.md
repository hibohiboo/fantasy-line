# 開発方針

以下の順序でステップを進めてください。
**各ステップは必ず Agent ツールを使ってサブエージェントとして実行すること。**
各ステップ完了後は、次のステップへ進んでよいかユーザーに確認すること。

## Step 1 — PBIの内容を確認する
Agent ツールを使い、`.claude/commands/dev.01.01.PBIの内容を確認する.md` の内容をプロンプトとしてサブエージェントを実行してください。

## Step 2 — ドキュメントを作成する
Agent ツールを使い、`.claude/commands/dev.01.02.ドキュメントを作成する.md` の内容をプロンプトとしてサブエージェントを実行してください。

## Step 3 — 実装計画を立てる
Agent ツールを使い、`.claude/commands/dev.01.03.実装計画を立てる.md` の内容をプロンプトとしてサブエージェントを実行してください。

## Step 4 — TDDで開発する
Agent ツールを使い、`.claude/commands/dev.01.04.TDDで開発する.md` の内容をプロンプトとしてサブエージェントを実行してください。
未完了のチェックリスト項目がなくなるまで1項目ずつ繰り返すこと。

## Step 5 — レビューを行う
Agent ツールを使い、`.claude/commands/dev.01.05.レビューを行う.md` の内容をプロンプトとしてサブエージェントを実行してください。
