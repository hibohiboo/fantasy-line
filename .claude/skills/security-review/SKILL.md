# セキュリティレビュー Skill

このプロジェクトでは以下を中心に確認する。

- API Gateway + Lambda の入力検証と権限
- S3 / CloudFront 公開設定
- XSS リスク
- IAM 最小権限と cdk-nag の遵守
- Secrets の取り扱い

---

## 目的

- 個人規模で現実的に防ぎきれるリスクを抜け漏れなくチェックする
- ZAP / CodeQL / Dependabot / cdk-nag の検査結果を正しく扱う
- 「動いた、で見落とす」を避けるためのレビュー手順を持つ

## 使用するタイミング

- API エンドポイント追加・変更
- 認証・認可ロジックの変更
- 入力を新たに受け取る箇所の追加
- CDK で S3 / CloudFront / Lambda / API Gateway の構成を変えるとき
- 依存ライブラリ追加・更新時
- セキュリティ系 CI（ZAP / CodeQL）が警告を出したとき

## 手順

### 1. スコープを確認する

- 影響を受けるエンドポイント・データ・リソースをリストアップ
- 信頼境界（外部入力が入る場所）を特定する

### 2. OWASP Top 10 観点で点検する

- A01 アクセス制御の欠落: 認可チェックは入っているか
- A02 暗号化の不備: 通信は HTTPS 強制か（HSTS）
- A03 インジェクション: 文字列結合でクエリ・コマンドを作っていないか
- A04 安全でない設計: 設計レベルの脆弱性（権限分離、入力検証境界）
- A05 セキュリティ設定ミス: S3 公開設定、ヘッダ
- A06 古い・脆弱な依存: Dependabot / `npm audit`
- A07 認証の不備: トークン保存・有効期限・回転（該当する場合）
- A08 ソフトウェア / データ整合性: ビルド・デプロイ経路
- A09 ログ・監視の不足: 監査・通知が落ちていないか
- A10 SSRF: 外部 URL を取得する処理（ある場合）

### 3. 入力検証の確認

- すべての外部入力が `zod` などで境界検証されているか
- 検証失敗時のメッセージに内部情報が漏れていないか
- ホワイトリスト方式になっているか

### 4. 認可・権限

- API の各エンドポイントで「誰が叩けるか」が明示されているか
- IAM Role はリソース単位で最小化されているか（ワイルドカードなし）
- S3 バケットの `blockPublicAccess` を確認する

### 5. Markdown / HTML の安全性

- Vue の `v-html` や `dangerouslySetInnerHTML` を使っていないか
- 外部リンクに `rel="noopener noreferrer"` が付いているか
- 信頼境界が同じでも防御を緩めない

### 6. Secrets

- ハードコードされた API キー・トークン・接続文字列がないか
- `.env*` がコミットされていないか
- ログ・エラー応答に Secrets が出ていないか

### 7. CDK / AWS リソース

- cdk-nag 警告 / エラーが解消されているか
- 抑制がある場合、理由・影響・見直し条件が残っているか
- Lambda の IAM Role がリソース単位・最小権限か
- S3 の `blockPublicAccess` / Origin Access Control が設定されているか
- ログに PII / Secrets が混ざっていないか

### 8. ZAP / CodeQL

- ZAP の対象エンドポイント一覧に追加すべきか確認する
- CodeQL の警告を理由なし suppress していないか

## チェックリスト

- [ ] OWASP Top 10 の各観点を確認したか
- [ ] 入力検証（`unknown` → `zod` narrow）が境界で行われているか
- [ ] 認可チェックの抜けがないか
- [ ] Secrets がコード・ログに漏れていないか
- [ ] IAM ワイルドカード（`*`）がないか
- [ ] S3 の公開設定が意図どおりか
- [ ] Markdown / HTML の XSS リスクがないか
- [ ] CDK 変更がある場合、cdk-nag 警告が対応済みか
- [ ] 修正優先度 CRITICAL / HIGH / MEDIUM / LOW で整理したか

## 禁止事項

- 修正優先度を付けない
- 根拠（OWASP のどの項目か / 該当ファイル）を書かない
- 「とりあえず safe」と曖昧に評価する
- ZAP / CodeQL の警告を理由なし suppress させる
- IAM ワイルドカード追加を承認する
- Secrets が一時的でもリポジトリに残ることを許容する
